## MEMBER SECTIONS
- Git

Git is a **version control system** that developers use to track changes in their code and manage different versions of a project. It allows you to save checkpoints of your work, called **commits**, so you can see what changed, return to an earlier version if something goes wrong, and experiment with new features without affecting the main project. Git also makes it easier for multiple developers to work on the same project by allowing them to create **branches**, merge their work, and resolve conflicts. In simple terms, **Git is like a detailed history and backup system for your code that also helps teams work together.**
